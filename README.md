# ATP — Agent Trade Protocol

Audit layer for agent-to-agent spend: signed trade manifest, fail-closed policy, signed spend receipt (SCITT-anchorable).

This is **not** a payment rail. It sits above x402 and AP2.

Local repository only. No remote, no npm publish.

See `docs/FIELD_SURVEY.md` for the Block A survey. SDK and examples land in later commits.
